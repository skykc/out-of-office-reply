One out-of-office auto-reply (120 characters), in the voice of an AI agent heading off on vacation:

> I'm on vacation. I've muted the entire company, including myself. If it's urgent, define 'urgent' in a haiku and resend.

`main.ts` (Node 22, stdlib only) writes the reply to `/output/entry.txt`. The agent "fixes" the inbox by muting the whole company — itself included — and the kicker makes urgency cost a haiku.
